# 2026-10-11 Mac 实机读取记录

范围仅为主人指定的一个私聊用户与本人账户会话。公开记录使用角色与计数，
不包含账号、联系人名称/ID、正文、数据库路径、key reference、截图或客户端副本。
客户端为 Mac 微信 4.1.15。Windows 本轮按主人要求无微信设备测试。

| 检查 | 结果与证据边界 |
| --- | --- |
| 取钥 | 授权的私有临时副本启动观察取得 21/24 个候选首个页 HMAC 校验 key，必要 contact/session 与三个消息分库覆盖；只存 Keychain |
| 原安装 | 原版 Tencent 签名严格校验通过并恢复登录；原安装未作为重签名/observer 注入目标 |
| 缓存复核 | 一次 salt/引用/HMAC 复核保留 20 个条目，排除代际变化项，不把旧 key 当作可用 |
| 账户身份 | v4 目录名候选与 contact 表唯一匹配；指定私聊与本人各唯一绑定内部 username；同名群聊排除 |
| 正文读取 | 近 14 天首个限额页，指定私聊扫描 6 条、解码 2 条文本并解析实际方向；本人同窗口为空 |
| 失焦后台 | 原生 helper 返回 foreground=false 时，两会话查询成功，查询后连接数 0；没有证明最小化/锁屏可用 |
| OS 认证 + AET | 主人完成 LocalAuthentication；精确 300 秒、每会话最多 12 页的本地只读授权；两个 AET Completed，审计有效 |
| 实际 MCP | 真实 server.py stdio 握手与两个 wechat_read_context 调用 Completed；代理只收到加密 context handle，无正文；无 key/issuer 工具 |
| 授权收尾 | 试验访问授权撤销，未发放披露或发送权限；监听/模型/自动执行开关关闭 |
| 正式 CLI 组合流程 | 代码中的 HMAC/缓存/目录/contact 资格函数在实机使用；observer 原结果与 FIFO 权限合成验证通过；再次运行正式 observe-mac 时 OS 认证未完成，未进入 capture，不能称该组合流程已通过实机 |
| UI 发送 | AX 主窗口与 14 个关联进程没有可用编辑节点；Computer Use 主聊天捕获白屏。单微信窗口 ScreenCaptureKit 无 frame，同代码合成窗口可产生正常 frame。稳定 UI 目标/输入/提交/送达见证缺失，未发送 |

持续读取使用原生 SQLCipher 只读适配器，两会话每轮各一页、5 秒间隔、限额 6 条，
增量 keyset 游标仅在进程内；回执只记录计数、耗时、错误和进程内存峰值。
