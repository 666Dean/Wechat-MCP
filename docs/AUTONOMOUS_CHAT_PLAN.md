# Mac 原号：自主选聊与限次发送

## 本轮验收范围

2026-10-15，本机原版客户端的两个既有私聊（一个联系人、本人真实 ID）已通过：
Agent 从主窗口搜索目标、核对稳定 ID、暂存精确测试草稿、切换会话观察本地缓存、
重新选聊载回输入、两次精确比较、一次提交及独立数据库记录核对。
每目标观察到一条本人发出的精确记录，审计有效；没有人工开独立窗口、复制或
按发送，没有截图、OCR、注入、客户端修改或捕获保护绕过。个人身份、文本、
窗口和详细执行记录只保留在本地。
随后公开 `owner_chat_send` 入口以两个新独立文本完成整份计划，两个目标各观察到
一条精确发出记录，退出码 0、结束撤权；并非只运行私有实验脚本。

这是**需要前台窗口的有限计划**。执行器可以从失焦状态激活微信，不代表无焦点
后台输入、全天自动回复、任意版本或所有联系人均已验收。数据库观察不是对端
送达证明；输入事务仍保留 Unknown，独立观察不改写旧回执，不允许重发。

## 设计与身份见证

主窗口没有可靠的聊天/输入 AX 节点，标题也不是收件人 ID。原版搜索菜单可用，
但成功按菜单或搜索过某个名字都不足以授权发送。

1. 对唯一原版进程及在屏主窗口固定 PID、窗口号和几何。隐藏登录窗口可能同名，
   不使用所有窗口中的第一个同名项。每步核对原进程打开的账号联系人/会话库。
2. 经“编辑 → 搜索”打开新的未命名对话框，精确复制核对搜索词。只在确认属于
   搜索对话框时按 Return；随后读取新搜索记录，确认唯一稳定 ID。
3. 暂存采用非覆盖输入、先收起文本选择，不删除或替换未知内容。非精确输入立即
   停止，可能保留本次插入的未发送内容，需主人检查。不能用旧缓存判定当前输入为空。
4. 切换到计划中另一个已授权私聊，使草稿写入缓存。只对当前拟发完整文本查询，
   要求唯一记录、精确正文及预期稳定 ID。
5. 微信重新激活会话会消费缓存。允许“刚刚精确缓存 → 新搜索选择同一稳定 ID →
   缓存为空或仍精确”这一转换；见证最长 60 秒，激活最长 30 秒，双时钟限制，
   窗口/账号/收件人/正文变化或其他草稿均拒绝。最终两次输入区精确比较仍不可少。
6. 写入并同步一次性尝试文件及父目录，再调用一次提交。独立 WCDB 有界核对
   精确正文、本人 sender、出站方向及非零 server_id，始终 `delivery_confirmed=false`。

[状态见证](../adapters/macos/chat_state.py) 是本地缓存与输入关联，不宣称为微信
公开的原生 wxid 控件，也不是发送权限。[Swift 实验辅助程序](../adapters/macos/experimental_chat_navigation.swift)
仍须原生 AXR 证明，绑定操作、资源、文本、窗口及导航命令。父执行器承担账号库
资格、权限来源、账号租约、去重和独立观察；没有通用任意键盘/SQL 工具。

## 本地所有者入口

[限次计划执行器](../axr_integration/owner_chat_send.py) 不注册为 MCP issuer。
Agent 可以准备精确计划，主人通过本机 OS 认证批准后，整份计划自动完成；人工回复
面板继续独立保留。默认人工提交不变。2026-10-16 新增的 [MCP 限时自动回复](AUTOMATIC_REPLY.md)
复用 `chat_executor.py`，由本机认证的有限会话接入任务完成流程；下面的计划 CLI
作为兼容入口保留，不再是 MCP 自动回复的必要前置条件。仍不声明全天运行。

开发者显式构建，不安装、不授予权限或自动运行：

```sh
python scripts/build_pinned_input.py --build .local-private/build --navigation
```

计划是权限为 `0600` 的本地 JSON，最多两条消息、两个既有绑定私聊；每条指定
另一个会话作为暂存缓存时的停靠目标，不读取该会话正文。标识必须来自已有
所有者配置，不使用昵称猜 ID，不支持群聊或文件传输助手替代本人。
文字必须已包含所有者配置中的 AI 署名，执行器不会在批准后悄悄改写正文。

```json
{
  "version": 1,
  "messages": [
    {
      "conversation_id": "fixture-peer-id",
      "parking_conversation_id": "fixture-self-id",
      "text": "【自动回复 · AI 助理】 已收到，我会整理后回复。"
    }
  ]
}
```

```sh
python -m axr_integration.owner_chat_send \
  --state "$AXR_OWNER_STATE" --plan "$AXR_LOCAL_PLAN" \
  --owner-helper "$AXR_OWNER_HELPER" --native-helper "$AXR_CHAT_HELPER"
```

可先加 `--check-plan` 只验证文件与结构，不碰微信、不认证或授予权限。正式执行
必须在交互终端，显示整份本地计划并要求本人 OS 认证；权限最长 20 分钟，最多
40 次本地元数据核对、每目标 8 次搜索、每条消息一次暂存/发送及 14 页读回。
计划正文按 personal 来源处理，发出前单独签发绑定输出意图与精确目的地的披露批准，
不把输入文件当作自动降级的数据。进程结束撤权、取消子进程、关闭只读连接；
详细结果加密/私有保存，不输出其他正文。

尝试标记按目标与精确文本持久去重；同一目标再次使用完全相同文本会被阻断。
不要删除标记来重试，也不要在 Unknown 后换一个编号冒充同一次任务重试。
菜单在尚未执行搜索 Return 且明确返回未发送时可重新打开一次；这不允许重复提交。

## 验证边界

原生证明回归不访问 UI；状态转换、歧义、重复文本、时间/窗口变化、撤权、私有计划、
已有草稿保留和 Unknown 停止使用合成数据。真实两个私聊的结果另记，不能把
fixture、编译或 CI 等同设备验收。Windows 不提供这个 Mac 执行入口；原有读取、
人工回复和 UIA 路径保持独立，未外推 Windows 自动发送资格。
