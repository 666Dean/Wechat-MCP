# WeChat MCP Developer Preview

macOS 开发者预览版 · `v0.1.0-dp2` · 2026 年 10 月 20 日

把微信私聊接入你的 Codex 工作流。此版内置 Qt 桌面运行时与独立 AXR 安全服务组件，
首次打开即可按向导完成本机部署、Codex 连接和访问范围设置，无需另行编译服务包。

## 平台与安装

- **仅支持 macOS 27.0+、Apple Silicon（arm64 / M 系列）**。本机验证为 macOS 27.0.1。
- 下载 DMG，核对 `SHA256SUMS.txt`，将 **WeChat MCP Developer Preview** 拖入 Applications。
- 本版为开发者预览，桌面 App 为 ad-hoc 签名，未进行 Apple 公证。遇到系统提示，请按
  [Apple 官方打开说明](https://support.apple.com/102445)核对来源；不要关闭系统整体安全保护。
- 暂不提供 Intel Mac、Windows 或 Linux 安装包。

## 首次打开：在 App 中完成设置

1. **准备本人数据**：选择本人微信账号的 `db_storage` 文件夹，核对稳定微信 ID。
   选择自己合法持有的原始数据凭据缓存，或已有 AXR 凭据索引。
2. **准备 Codex**：按向导获取、登录 Codex；使用官方浏览器登录，不向 App 或聊天提供密码。
3. **安装 AXR**：App 验证内置组件并请求管理员安装。随后在本机硬件认证下初始化身份，
   原生校验并导入凭据；此步骤不授权读取聊天正文或发送消息。
4. **授予系统权限**：按向导为 AXR Authority 开启数据访问和设备控制，系统操作由本人确认。
5. **连接 Codex**：审核并写入独立 MCP 配置，选择助理所在的 Codex 对话；其余配置保留。
   已打开的 Codex 连接可能需要刷新。
6. **选择权限**：核对联系人、用途、有效期与次数，完成风险确认和本机签名。
   七项实际就绪检查全部通过，才能完成向导。

**微信数据凭据需要使用者事先合法持有。** 此 App 不从微信进程提取密钥，不能使用微信
密码代替数据密钥，也不绕过 macOS 或微信隐私保护。公开包不带任何人的账号配置、
密钥、聊天、Codex 登录和既有授权。新安装不会恢复他人的权限。

## 支持的功能

| 功能 | 体验与范围 |
| --- | --- |
| 对话工作台 | 绑定并切换 Codex 对话，在桌面交办任务，忙碌时排队，查看执行状态与结果 |
| 模型与思考强度 | 实际模型目录、紧凑二级选择、支持的思考档位及恢复默认 |
| 受控 MCP | 授权私聊目录、分页文字读取、人工草稿、主动单次发送及任务状态 |
| 新消息自动回复 | 仅处理开启后的授权新入站文字；合并连续消息并结合本来源上下文后回复 |
| 原号私聊发送 | 自动选聊、稳定身份核对、精确正文比较、单次提交和独立数据库核对 |
| 人工回复 | 独立草稿面板，保留手动核对和处理方式 |
| 联系人和授权 | 搜索、筛选与分页；草稿、自动回复、完全访问三档；时长和次数可设为不限 |
| 本人任务入口 | 单独授权本人私聊后，`/agent` 可向绑定的 Codex 对话交办任务；敏感操作继续确认 |
| 助理偏好 | 导入人设、设置回复风格，选择是否附带回复内 AI 署名；状态与审计持续保留 |
| 桌面外观 | Qt 6 / QML、浅深色主题、圆角磨砂浮层、简洁图标、设置向导与快捷权限入口 |

普通联系人的文字进入无工具的隔离回复 Agent，不会因此获得本人任务工具权限。
所有功能均以本机环境兼容、本人精确授权和连接就绪为前提。

## 发送方式

本版优先使用 **切换微信到前台发送**，会临时使用系统剪贴板。发送期间请避免同时编辑
微信输入区。也可选择等待电脑空闲，或仅在微信本已位于前台且空闲时执行。
**无前台、不干扰用户的后台发送当前不提供。**

已有文字或附件默认保留；强制覆盖需要单独确认并纳入签名范围。停止、授权到期或
退出服务后撤权，重启不恢复旧队列。发送结果不确定时记录为 **Unknown，永不自动重发**；
换请求号也不能重复提交同一条已知不确定正文。数据库存在精确发出记录不等于对端送达。

## 隐私与安全

- 独立 AXR Authority 负责权限、原生凭据和执行证明，桌面与模型不能自行发权。
- 管理员安装、硬件身份签名和系统隐私权限由本人完成，敏感权限变更具有独立确认界面。
- 数据文件代际、签名组件、目标身份和输入内容都要核对；异常时停止，不降级绕过保护。
- 回复模型按来源隔离，输入有界；入站先检查变化，再按需读取与推理，减少重复计算。
- Codex 由使用者安装和登录，公共包不再分发供应方 Codex App；本机部署核验并固定使用者的签名运行程序。
- 公开源码和安装包不包含个人测试记录、联系人、账号部署、运行账本或密钥。

## 使用边界

这是第一阶段的开发者预览，聚焦私聊文字、任务和回复。群管理、支付/转账、朋友圈、
小程序、账号操作和附件自动发送不在本版支持范围。简报、待办与附件入口仍在迁移，
不作为完整可用的功能承诺。多日无人值守、全天功耗和其他系统/硬件需独立验证。

安装、运行时、合成测试与微信实机验证分别记录；向导不会偷偷发送验收消息。
本机正式 MCP 已验证授权私聊的自动选聊、单次前台提交和精确数据库记录读回，
并由所有者在手机确认可见；该结果不代表所有设备或长期无人值守均已验证。
