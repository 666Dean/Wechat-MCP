# WeChat MCP Developer Preview

首个 macOS 开发者预览版 · `v0.1.0-dp1` · 2026 年 10 月 19 日

面向愿意配置本机安全服务并反馈问题的开发者。此版本把 Qt 桌面、Python 运行时和
必要依赖打包为可移动的 App，不再依赖打包者的代码目录或虚拟环境。

## 下载与平台

- 仅提供 **macOS / Apple Silicon（arm64，M 系列）** DMG。
- 当前二进制最低系统为 **macOS 27.0**，本机验证为 27.0.1；未宣称较低版本兼容。
- 本次没有 Intel Mac、Windows 或 Linux 安装包；源码中的其他平台代码不代表本次支持。
- 名称：**WeChat MCP Developer Preview**；版本：`0.1.0-dp1`。
- 发布为 GitHub **Pre-release**，不替换已有稳定版本的 Latest 标记。

## 安装与首次设置

1. 核对同页 `SHA256SUMS.txt`，打开 DMG，将 App 拖入 Applications。
2. 启动 App，按首次向导检查本地服务、微信数据访问、设备控制、Codex 对话和授权范围。
3. **真实微信功能还需要本人账号的 AXR 独立安全服务部署及已有凭据准备**，详见
   [独立服务部署](https://github.com/666Dean/Wechat-MCP/blob/v0.1.0-dp1/docs/INDEPENDENT_SERVICE.md)。公开 DMG 不包含任何用户的服务部署配置，
   不会从开发者电脑复制密钥、微信账号、聊天、Codex 登录或既有授权。它不是新机器
   无需配置即可自动回复的通用安装器。
4. Codex 需要用户自行安装并登录；DMG 不再分发供应方应用或代为登录。范围和构建
   需要本机所有者确认；系统权限仍由用户自己授予，App 不自行签发权限。
5. 向导逐项实际检查，全部通过并复核后才标记完成；向导本身不读取聊天正文或发送测试。

此预览包为 **ad-hoc 签名，未进行 Apple 公证**。系统可能要求用户在“隐私与安全性”
中核对并批准打开，参考 [Apple 官方说明](https://support.apple.com/102445)。不要关闭
系统整体安全检查，不要对来源不明的副本放行。正式安全服务仍保留其独立构建、
安装及硬件身份校验，桌面包不会降低这些要求。

## 安全设计

- 读取、披露、发送和本人任务由独立 AXR 权限服务控制；桌面和 MCP 不保存通用发权凭据。
- 所有者审查目标、数据目的地、时限及次数，敏感权限变更二次确认和本机硬件签名。
- 已有输入默认保留；强制覆盖必须单独批准并进入签署范围。
- **Unknown 永不自动重发**；换请求号不能重发已知不确定正文。数据库记录不等于对端送达。
- 停止撤权；重启不恢复旧权限或旧任务。不绕过微信窗口隐私保护，不使用注入或 OCR 强行捕获。
- 普通入站按来源隔离、有界处理，连续文字合批；减少重复推理和无变化查询，未作全天功耗承诺。
- 不包含微信/Codex 账户凭据、私人联系人和聊天、授权账本、部署配置或本机测试记录。

## 已知限制与验收边界

1. **可靠的原号无前台发送尚未跑通。** 当前键盘发送仍会使用微信前台及临时剪贴板；
   “空闲后发送”仍会置前微信。“仅微信前台且空闲时”会等待用户正常切回，不主动抢占
   其他应用。打开发送设置时有明确说明，未通过的后台能力不显示为可用开关。
2. 历史实机曾完成指定私聊的主动发送、新入站自动回复及精确数据库观察；**最近两次新
   测试虽有原生单次提交，但未查到精确数据库记录，均保留 Unknown、没有重发**。
   本版不是所有设备/所有发送路径均已通过的稳定版。
3. 首次服务部署仍属于开发者配置，需要本人账号准备、兼容的微信数据与本机系统权限；
   公开桌面 DMG 不包含私人服务包，不能跳过这一步。
4. 本人任务排队已接入，完整返回和长期同对话稳定性需持续验收。简报、待办、附件等
   入口不代表已全部完成独立服务迁移；不把它们列为本次完整可用的功能承诺。
5. 暂不支持群管理、支付/转账、朋友圈、小程序和账号操作；不支持附件自动发送。
6. 当前微信窗口、输入和前台环境变化可能导致安全停止。服务升级后，Codex 中持有的
   旧 MCP 连接可能需要重连；不会为了连接便利复用旧构建授权。
7. 多日无人值守、全天功耗、Intel Mac、其他 macOS 版本和 Windows 实机未通过本次验收。
