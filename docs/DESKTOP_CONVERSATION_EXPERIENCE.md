# 桌面对话、访问管理与连续消息

工作台以对话为中心。桌面输入和已单独授权的本人微信 `/agent` 任务，进入同一个
绑定的 Codex 对话；简报、待办和待授权作为项目入口，人工回复保留独立面板。
普通联系人仍使用单来源、无工具的隔离回复提供方，不能进入开发对话。

## 对话与权限

输入框左侧提供文本参考资料和微信权限菜单；右侧一个入口管理模型与思考强度，
先打开强度浮层，再点击其中的模型名称进入列表。所有菜单在窗口边界内展开。
模型目录来自公开 App Server 的 `model/list`，所选值实际传入 `turn/start`，适用于
该对话后续任务；目录不是账号可调用资格证明，失败不会偷偷切换其他模型。
实际 `item/agentMessage/delta` 事件驱动正文更新，不伪造打字内容。
模型与权限菜单、悬停提示共享半透明圆角浮层；思考强度使用真实模型提供的档位
滑条，可恢复模型默认值。设置采用分类栏与限宽分组表单，字段/值及操作统一对齐，授权勾选与键盘焦点统一。

| 访问级别 | 实际范围 |
|---|---|
| 仅生成草稿 | 所选会话的本地读取和模型分析；发送目标为空，自动和 MCP 发送均拒绝 |
| 自动回复 | 所选会话的新消息读取、模型分析及原会话回复 |
| 完全访问 | 上述回复权限，加上本人 `/agent` 向绑定 Codex 对话下任务；其他联系人不能使用任务工具 |

完全访问先显示圆角风险窗口、模糊背景及浅红色“已知风险，继续”。继续后还须
核对联系人、期限、次数和草稿覆盖选项，并由本机所有者签署精确范围。风险窗口
不是授权凭证，取消不会改变权限。更改生效范围会先停止旧权限；认证取消后保持
停止，不恢复旧权限。停止无需再次认证。

联系人支持名称/ID 搜索、已授权/本次已选筛选、每页 30 项、单独取消和清空选择。
“全部”状态下取消一个目标，会转为精确选中其余目标；不会创建几千个卡片。
强制覆盖仍默认关闭，且必须进入本机签署的范围。

桌面任务只把结果留在桌面对话，不会自动发送到微信。本人微信任务的结果通过
既有受控发送链返回本人会话。普通 MCP 不提供桌面任务、签发、设置或取消权限工具。
任务使用稳定请求号，忙碌时排队，交接后结果不确定不重做；停止任务不等于撤回
已完成的外部副作用。命令和文件审批仍为单次确认。任务成功入队才清空对应输入；提交失败保留文字与
参考附件，等待期间的新编辑不会被旧成功回执清空。

## 连续消息与上下文

同一来源在最后一条新入站后等待约 3 秒，持续来信时最多等待约 12 秒再处理；
尚有未读分页时先排空分页。每次模型披露仍最多 6 条、24KB，超长连续来信分为
有界批次；不会扩大到其他来源。可结合本轮授权之后已读取的同会话上下文，
出站内容只作为背景，不会触发新的回复。不能据此读取授权前的历史。

合并缓冲和上下文仅在本机内存中短时保留，停止/重新授权时清除，不从重启中恢复。
每批推进游标和建立唯一任务先于模型调用，失败或 Unknown 不重放。需要回复才
启动隔离提供方，空闲仍使用数据库变化门控。每来源最多保留 96 条待处理消息，
全局最多 128 个来源；超限在追加前拒绝并暂停撤权，界面提示重新核对；需要本机所有者重新开启。

## 搜索与交互反馈

搜索粘贴后给异步结果有界稳定时间。鼠标位于结果区域时，仅移动到已核验窗口内
的安全空白位置，没有点击；用户移动鼠标就停止选择，只有指针仍属于本次操作时
才恢复原位置。回车只在预期搜索窗口执行，误入历史窗口会在输入正文前停止。
新鲜稳定 ID、原生实时草稿保护、精确文本和最终单次认领继续强制执行。

这修正了固定短等待与悬停干扰路径，不保证所有微信版本或任意用户干预都能成功。
没有 OCR、注入或更改微信窗口保护。实际设备结果以 [状态文档](STATUS.md) 为准。

顶部只保留对话标题和连接状态；通知跟随当前内容，不再固定在页面底部。
导航、项目项和输入控件共享间距、圆角和选中态。短过渡、按压反馈和仅执行时
活动的状态动画可在设置中关闭；隐藏时降低正文事件刷新频率。

协议依据 [OpenAI App Server 文档](https://learn.chatgpt.com/docs/app-server)。

## SDK 通信一致性

跨语言通信的 MAC 与根签名统一使用原生 JSON 序列化。Python 与 C++ 对相同二进制
浮点值可能选择不同十进制字节；此前这会造成偶发验签失败。持久化账本、资源和
检查点仍使用原有摘要规则，不隐式迁移。只有读取历史收据可验证旧签名字节；当前
执行证明必须使用新格式。程序更新仍撤销旧权限，不延长证明或最终提交期限。
