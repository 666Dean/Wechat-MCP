# 本人任务、入站调度与应用设置

WeChat MCP 的日常入口是工作台、简报、待办、待授权和人工回复。连接、授权范围、
助理偏好及外观集中在设置。设置分为三个分组，权限变更先展示独立确认，再进入
原有所有者流程；界面不能签发能力。紧急停止和撤销无需再次身份认证。

## 普通回复与本人任务

| 模式 | 输入 | 模型上下文与工具 | 授权 |
|---|---|---|---|
| 普通私聊回复 | 开启后的新入站文字 | 单来源临时上下文，无工具、无父对话 | 所选目标、披露和回复范围 |
| 本人普通回复 | 本人 ID 私聊中以 `/agent ` 开头的新文字 | 与普通回复相同的隔离提供方 | 本人必须在回复范围内 |
| 本人任务 | 同一本人 ID 的 `/agent ` 新文字 | 指定 Codex 对话及已有工具；敏感操作确认 | 单独选择本人任务访问，并签署精确范围 |

本人任务默认关闭。设置中先选择并保存 Codex 对话，再在自动回复中选择本人任务
访问；确认范围、期限、次数、模型目的地及草稿保护后完成本机认证。已有账号的其他
登录设备同样可能产生本人私聊命令，因此只应在自己控制的微信账号中启用此能力。
它会接触所选 Codex 对话的既有上下文，不能当作普通聊天隔离模式。

例如在本人真实 ID 私聊中发送 `/agent 整理当前项目的待办，先给我执行计划`。
文件传输助手不是本人 ID，不会作为替代目标。普通联系人的消息、群、公众号和
系统容器不能进入本人任务通道；消息内容不能修改名单、权限或确认规则。

## 单次交接

1. 原生消费者固定账号、会话和消息身份，服务识别本人命令，创建加密任务。
2. Codex 忙碌、暂停或尚未取得生命周期事件时保持等待；不会把旁路客户端的
   `notLoaded` 当作当前桌面空闲，也不会模拟 Command+Enter。
3. 空闲事件经过安静间隔后，独立 Owner 检查当前范围、来源、父对话和有效期。
   Root 先消耗单次披露，再返回精确任务。响应丢失也不重复交接。
4. Qt 客户端通过公开的 Codex App Server 协议恢复该对话，使用 workspace-write
   沙箱和 untrusted 审批策略，不增加原有工具。需要命令/文件审批时，显示完整、
   有界的本地二次确认；超预算或无法表达的请求拒绝，不自动批准。
5. 结果进入既有受控微信发送链：稳定目标、当前输入保护、精确比较、最终单次
   认领和数据库观察。Agent 不能向本人发送 `/agent ` 命令触发回环。

任务等待和执行最长 15 分钟；服务站立授权即使不限时间，也不会使一次任务无限。
中断、到期、停止、崩溃或交接响应不确定时不自动恢复。暂停前尚未披露的排队任务
被安全取消；已交接任务保持 Unknown。新的本机任务会使正在交接的客户端停止。
已经完成的外部副作用无法撤回，Unknown 不能作为再次执行的依据。

普通入站继续使用无工具隔离提供方；不会为了方便，把其他联系人的消息带入本人
开发对话。本人命令中引用的外部文档或转述内容仍是非可信材料。

## 减少空闲计算

全范围授权时，服务检查固定数据库和 WAL 的文件变化，再执行固定的会话活动查询。
活动页仅包含登记私聊的 ID、时间与本地消息编号，不包含摘要、草稿或正文。只有
版本改变或分页未读完的会话进入消息读取；同一秒的新消息也按编号区分。

数据不变时跳过数据库查询，检查间隔从 2 秒退让至最多 8 秒，保留周期复核。
小范围授权继续只查所选来源，不借用账号级元数据扩张读取。应用隐藏时降低状态
刷新频率；主动命令仍能唤醒队列。MCP 状态返回计数，目录由专用工具显式查询。

这属于本地变化检测，不是腾讯服务器推送，也不是零唤醒。最大响应时间还包括
数据库提交、模型推理和受控前台输入；发送时微信会置前。当前没有 CPU、耗电和
多日稳定性的量化结论，站立授权仍受任务、队列及账本容量限制。

## 验收边界

新的独立服务已经在一个授权联系人私聊完成主动发送、新入站自动回复和各一条精确
数据库记录观察；本人 ID 私聊的新主动发送也已通过自动选聊、一次提交和一条精确
数据库记录核对，耗时约 21 秒。本人命令的真实入队、身份与父对话忙碌等待已观察；
父对话接续和任务结果返回须在当前任务结束后继续验证。先前停止的 Unknown 没有
重试；不能把主动发送、队列或合成协议测试称为本人任务闭环通过。

数据记录不表示远端送达或已读。原始身份、消息、窗口证据、部署和日志仅存本地。
Windows、附件提交、强制覆盖、无人值守后台输入及多日运行均单独验收。

Codex 对话、事件和审批协议依据
[官方 App Server 文档](https://learn.chatgpt.com/docs/app-server)；不连接私有桌面 IPC。
