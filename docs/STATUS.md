## 如何理解证据

- **已实现并模拟验证**：代码存在，自动测试使用 MockAdapter 或模拟 MCP 服务。
- **已实现，未实机验证**：有真实适配代码，但没有实际微信收发证据。
- **未实现**：代码当前不提供该能力。
- **未知**：需要版本、设备、账号或真实场景实验才能判断。未知不能当作兼容承诺。

## 明确未完成

1. **所有好友常驻监听**：新增数据库后端可在工具调用时读取显式绑定的后台会话，
   没有文件监听、定时对账器或自动授权全部好友；见 [数据库读取边界](DATABASE_READER.md)。
2. **全天自动回复**：没有常驻 AI 模型调用、事件调度、模型 API 集成或可靠服务管理器。
3. **关机后继续运行**：没有云端执行环境。现有 Windows UI 适配器需要运行中的设备和微信。
4. **对话理解**：不会可靠识别一句话是对主人还是对 Codex 说；基于提示让 AI 判断。
5. **实时检索与个人知识库**：没有联网知识验证、可分享资料白名单或知识库模块。
6. **附件及群聊**：不处理图片、语音、文件、群消息、撤回、转发和历史补录。
7. **独立身份认证**：已提供启动时管理能力开关，但没有账户认证或所有者签名；显式开放后的调用来源仍依赖可信 MCP 客户端。见 [认证说明](AUTHENTICATION.md)。
8. **硬性语义限制**：不替主人承诺、不跨聊天披露资料等属于模型提示，尚非程序级语义保护。
9. **运行维护**：已有追加列迁移；没有完整启动自检、健康恢复、状态清理界面或长期监控。
10. **GUI 和安装包**：没有图形设置页、可执行文件签名或免 Python 安装包。

## 功能承诺边界

首次发送及其他真实测试必须基于具体使用者的授权；公开 CI 只用模拟数据。
