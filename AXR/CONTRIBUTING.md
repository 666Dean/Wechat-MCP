# AXR SDK 贡献

AXR SDK 自有代码采用 `AGPL-3.0-only OR LicenseRef-Stellaria-Commercial-1.0`。
新贡献遵循 [Stellaria CLA 1.0](legal/Stellaria-CLA-1.0.md)，完整签署与核验流程见
[独立 SDK 贡献指南](https://github.com/Stellaria-Studio/Stellaria-AXR-SDK/blob/main/CONTRIBUTING.md)。

普通 PR 勾选、DCO、GitHub 昵称或单纯提交代码不替代有效签约。维护者合并前应核对实际
受让方、贡献者身份/权限、签署版本、具体提交哈希、第三方来源及接受记录；私密签署材料
不得进入公开仓库。历史贡献不因新 CLA 自动转让，本次双授权另由权利方确认。

本目录之外的集成代码继续依仓库原许可；本指南不将其自动纳入 AXR 的贡献转让安排。
开发验证请在集成仓库根目录按原 [CONTRIBUTING.md](../CONTRIBUTING.md) 执行，
独立 SDK 的构建与测试命令见独立仓库。
